# Quizz Educacional

Um quiz interativo em HTML, CSS e JavaScript que ajuda estudantes a praticar inglês e lógica de programação.

## Sobre o projeto

- Projeto focado em aprendizagem gamificada.
- Oferece 20 perguntas por sessão.
- Possui categorias: `Todas`, `Inglês` e `Lógica`.
- Feedback imediato e pontuação ao responder.
- Interface responsiva para celular e desktop.

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Como usar

1. Abra `index.html` em um navegador moderno.
2. Digite seu nome.
3. Escolha uma categoria.
4. Clique em `Começar quiz`.
5. Responda as perguntas e avance para ver o resultado.

## Estrutura do projeto

- `index.html` — marcação da interface do quiz.
- `style.css` — estilos visuais e layout.
- `script.js` — lógica do quiz e controle de fluxo.
